# North America Sales Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance across North America, providing insights into sales, profitability, product categories, and regional performance.

## Dashboard Features
- **Key Performance Indicators (KPIs):** Total Sales, Total Profit, Sales Quantity, CM, and PM.
- **Sales & Profit Analysis:** Monthly comparison of sales and profit.
- **Category Analysis:** Sales distribution across Office Supplies, Furniture, and Technology.
- **Regional Analysis:** Sales performance across Canada, USA, and Mexico.
- **Product-Level Analysis:** Detailed breakdown of sales, profit, and quantity by product.
- **Interactive Filters:** Dynamic filtering by Month, Product, and Region.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Power Query
- Data Visualization
